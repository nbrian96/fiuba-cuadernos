<AcademicBlock kind="statement" title="Enunciado oficial">

Proponer un algoritmo randomizado de tipo *Las Vegas* para resolver el problema de las $N$-Reinas. Puede encontrar una solución o fallar. Si falla, se repite el ensayo desde cero. ¿Cuál es la cantidad esperada de veces que hay que repetir el ensayo?

</AcademicBlock>

<SolutionDrawer client:load exerciseId="tda-adv-rand-nreinas">

#### Diseño del Algoritmo y Análisis

1. **Procedimiento por Columnas:** Para la columna $c = 1 \dots N$, identificamos las filas donde colocar una reina no cause ataques con las reinas ya ubicadas.
2. **Elección Aleatoria:** Entre las casillas libres válidas de la columna $c$, elegimos una al azar con probabilidad uniforme.
3. **Condición de Fallo:** Si en alguna columna $c$ no queda ninguna casilla libre disponible, el algoritmo **falla** y se detiene (no hace backtracking pesado).
4. **Éxito:** Si llega a ubicar las $N$ reinas sin conflicto, devuelve la solución (que es $100\%$ válida, condición de *Las Vegas*).
5. **Cantidad Esperada de Repeticiones:** Si cada ensayo independiente tiene probabilidad de éxito $p > 0$, la variable aleatoria $X$ (cantidad de ensayos hasta el primer éxito) sigue una distribución geométrica:

$$E[X] = \frac{1}{p}$$

Para $N=8$, empíricamente $p \approx 0.1293$ (aproximadamente 1 de cada 8 intentos triunfa), requiriendo en promedio solo $\approx 7.7$ corridas ultrarrápidas.

#### Comparativa Empírica e Implementación de Clase Práctica

| Estrategia ($N = 8$) | Estados explorados promedio | Observación |
| :--- | :---: | :--- |
| **Backtracking determinístico** | `114` de `2057` posibles | Retrocede fila a fila cuando hay ataque. |
| **Las Vegas (sin backtracking)** | **`56`** estados esperados | Falla rápido si una fila no tiene casillas válidas y reinicia desde cero ($p = 0.1293$). |

```python
import random

def QueensLasVegas(n):
    board = [[0 for _ in range(n)] for _ in range(n)]
    availColumns = list(range(n))
    R = 0
    while len(availColumns) != 0 and R < n:
        temp = [i for i in availColumns if isSafe(board, R, i)]
        if len(temp) == 0:
            return False
        rand = random.choice(temp)
        board[R][rand] = 1
        R += 1
        availColumns.remove(rand)
    return board
```
